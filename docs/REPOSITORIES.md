# Related repositories
The other projects around Beyond Good & Evil and the Jade engine, what each one covers and under which license.

The license decides how a project can be used here (this one is MIT):
- **MIT-compatible**: the code can be reused, with its notice.
- **GPL**: the code can't be copied into an MIT project, the formats and facts it documents can be reimplemented.
- **None**: all rights reserved by default, the project is a reference only (or ask its author).
